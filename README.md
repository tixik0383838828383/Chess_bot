# Chess_bot

Android-приложение с шахматным ботом на движке [Fairy-Stockfish](https://github.com/fairy-stockfish/Fairy-Stockfish), который работает прямо на телефоне, без интернета.

- Десятки вариантов шахмат (Crazyhouse, Atomic, Xiangqi, Shogi, Capablanca и др.).
- Режимы: **игрок против бота** и **бот против бота**.
- «Макс. мощность»: все ядра, большой хэш, Skill Level 20, настраиваемое время на ход.

APK собирается в GitHub Actions: вкладка Actions → последний запуск → Artifacts → `Chess_bot-apk`.
